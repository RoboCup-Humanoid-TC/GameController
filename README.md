# GameController

This was the GameController software for robot soccer games in the [RoboCup](https://robocup.org) [Humanoid League](https://humanoid.robocup.org) until 2025.

From 2026 on, the Humanoid League is superseded by the [Humanoid Soccer League](https://hsl.robocup.org), which uses [this GameController](https://github.com/RoboCup-HumanoidSoccerLeague/GameController).
